
# MatchMate

A modern SwiftUI matchmaking application demonstrating:

- MVVM Architecture
- Async/Await Networking
- Core Data Offline Caching
- Search Functionality
- Accept/Decline Persistence
- Animated Splash Screen
- Modern SwiftUI UI

## Features

- Fetch users from remote API
- Offline support with Core Data
- Search profiles
- Persistent accept/decline state
- Modern responsive UI
- Animated splash screen

## Tech Stack

- SwiftUI
- MVVM
- Core Data
- URLSession
- Async/Await
